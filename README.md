📌 Sobre o Projeto
Este repositório contém o código-fonte do Guia Digital Interativo, uma aplicação web desenvolvida com o objetivo de promover a alfabetização e inclusão digital da população idosa.
O projeto foi planejado e executado no Centro de Convivência da Pessoa Idosa (CCPI), localizado no município de Abaetetuba – PA, visando capacitar os participantes no uso autônomo e seguro de smartphones, aplicativos do cotidiano e navegação na internet.
🎯 Objetivos de Desenvolvimento Sustentável (ODS)
Este projeto alinha-se aos seguintes Objetivos de Desenvolvimento Sustentável da Organização das Nações Unidas (ONU):
🎓 ODS 04 – Educação de Qualidade: Promoção do aprendizado contínuo e capacitação digital para a terceira idade.
⚖️ ODS 10 – Redução das Desigualdades: Democratização do acesso à informação e redução do analfabetismo digital.
♿ Princípios de Desenho Universal Aplicados
A interface da aplicação foi projetada considerando os critérios de acessibilidade e usabilidade para o público idoso:
Uso Igualitário e Adaptável: Layout responsivo compatível com diversos tamanhos de tela.
Interface Intuitiva: Navegação simplificada com elementos visuais de fácil identificação.
Informação de Fácil Percepção: Tipografia ampliada, botões destacados e alto contraste de cores para facilitar a leitura.
Baixo Esforço Físico: Áreas de toque ampliadas para mitigar dificuldades com o manuseio de telas touchscreen.
📁 Estrutura de Arquivos e Gerência de Configuração
A aplicação foi estruturada de forma modular para garantir um bom gerenciamento e facilidade em evoluções futuras:
guia-inclusao-digital-idosos/
├── index.html        # Estrutura semântica e acessível do guia web
├── style.css         # Estilização visual (alto contraste, fontes grandes e áreas de toque)
├── script.js        # Lógica de interatividade dos módulos educativos e dicas
└── README.md         # Documentação completa do repositório


🛠️ Tecnologias Utilizadas
HTML5: Marcação semântica com recursos de acessibilidade.
CSS3: Estilização responsiva e adaptada para baixa visão.
JavaScript (ES6+): Interatividade dinâmica nos módulos práticos do guia.
Git & GitHub: Versionamento, controle de configuração e hospedagem do código.
